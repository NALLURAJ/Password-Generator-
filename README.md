# Password-Generator-
A secure and flexible password generator built in Python.   Users can choose length, and what types of characters to include.

---

## Features

- Select password length
- Include lowercase, uppercase, numbers, and symbols
- Randomly generates secure passwords
- CLI interface

---

## Technologies Used

- Python
- `string` and `random` modules
